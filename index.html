5Values and References

        
Why copy = original is dangerous for objects, and how to copy safely.

        
Part A — same reference

        
const original = { name: "Alice", score: 10 };
const copy = original;
copy.score = 99;

        

        
Why: objects are reference values. copy = original copies the memory address, so both point to the same object.

        
Part B — shallow copy with spread

        
const original2 = { name: "Alice", score: 10 };
const properCopy = { ...original2 };
properCopy.score = 50;

        

        
Part C — spread only copies one level deep

        
const userA = { name: "Alice", address: { city: "Almaty" } };
const userB = { ...userA };
userB.address.city = "Astana";

        

        
Correct nested copy: { ...userA, address: { ...userA.address } } (or structuredClone(userA)) — shown below.

Code

        
const add = (a, b) => a + b;
const multiply = (a, b) => a * b;

function calculate(a, b, operation) {
  return operation(a, b);

Output

add vs add()? add is a reference to the function; add() calls it.

      


      

        
8Scope

        
Global, function, and block scope, plus var vs let vs const leakage.

        
Code

        
const message = "global";

function scopeDemo() {
  let message = "function";
  const insideFunction = message;
  {
    let message = "block";
    var insideBlockValue = message;
  }
  const afterBlock = message;
  return { insideFunction, insideBlockValue, afterBlock };
}

{
  var varInBlock = "I am var";
  let letInBlock = "I am let";
  const constInBlock = "I am const";
}
varInBlock;
letInBlock;
constInBlock;

        
Output

        

        
Global scope — declared outside any function/block, visible everywhere.

        
Function scope — variables inside a function are only visible in that function.

        
Block scope — let/const inside { } only exist in that block.

        
var vs let vs const — var ignores block boundaries; let/const are block-scoped; const can't be reassigned.

      


      

        
9Closure

        
A counter factory whose returned function "remembers" its own private count.

        
Code

        
function createCounter() {
  let count = 0;
  return function () {
    count += 1;
    return count;
  };
}

const counterA = createCounter();
const counterB = createCounter();

counterA(); counterA(); counterA();
counterB();

function createAdder(value) {
  return function (x) { return x + value; };
}
const addFive = createAdder(5);
addFive(10);
addFive(20);

        
Output

        

        
Why it works: a closure keeps a live link to the variables of the scope it was created in. Each call to createCounter() makes a fresh count.
